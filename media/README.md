# Media folder

Drop karaoke files here (subfolders are fine), then press **Rescan media folder** in the host dashboard.

| You have | Name it like | Shows on stage as |
|---|---|---|
| A karaoke video (lyrics burned in) | `Artist - Title.mp4` (or .webm/.m4v/.mov) | The video, full screen |
| A backing track + timed lyrics | `Artist - Title.mp3` **and** `Artist - Title.lrc` | App-rendered lyrics with word-by-word highlighting |

Audio can be .mp3, .m4a, .ogg, .opus, .wav or .flac. `[ti:]`/`[ar:]` tags in an LRC file override the filename.
